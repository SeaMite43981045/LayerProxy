Logging Page

  • Monospace log viewer using NLog or custom scrollable div with NCode-style styling

  • System Config tab: Web Port, Port Start At, Wildcard Domain, Wildcard Main Port (read from config.json)
  • Preferences tab: Language selector (Chinese/English), default theme preference
  • Save buttons per tab with validation
