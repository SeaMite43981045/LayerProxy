Dashboard 更新点

  • CPU 卡片：型号、核心/线程数 + 使用率进度条 + 图标（Lucide: Cpu）
  • 内存卡片：总容量、已用/可用 + 使用率进度条 + 图标（Lucide: MemoryStick）
  • 系统卡片：OS 名称、版本号、运行时间 + 图标（Lucide: Monitor）
  • 实例列表：保持原 HomeView 的 NDataTable 样式

日志页更新点

  • 左侧面板：日志文件列表，每项显示文件名 + 下载/删除按钮
  • 右侧面板：实时日志流（SSE），带连接状态指示和清空按钮
  • 清空按钮使用 Naive UI 的 NButton 默认样式，不自定义 mock 样式

设置页更新点

  • 每个配置项采用 "标签+解释" 的左右布局（标签在左，输入框在右）
  • 每项都有 subtitle 解释其作用
  • 使用 NForm / NFormItem 保持样式统一美观
